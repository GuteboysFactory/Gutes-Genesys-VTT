# Compendium Talents

1. Put a Talent in an Item Compendium. Library → Load / refresh Compendiums: entry appears with pack label.
2. Open source opens that document; locked pack stays locked.
3. Purchase with valid XP/pyramid; actor copy remains independent.
4. Player cannot load private packs. Remove pack visibility: entries are excluded.
5. Edit/delete a pack Talent, then refresh. Verify updated entry/no deleted entry.
6. World Talents and existing reference entries remain available.

Explicit loading is required for Compendiums. Catalog materialization and Tome integration are still pending. Live QA pending.
