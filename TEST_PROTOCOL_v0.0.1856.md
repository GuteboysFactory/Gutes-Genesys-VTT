# v0.0.1856 — Renewal activation prompt and chat

1. Start Side Slots. Activate a new Heroic with Renewal as active GM: Cool/Vigilance dialog opens automatically.
2. Choose Cool or Vigilance: one Renewal PC slot and one result message in chat. Story Points and Heroic usage are charged only by the original activation.
3. On another activation, Cancel: Heroic stays active; no slot or Renewal roll. Resolve through Actions when appropriate.
4. Click the Actions retry button after success: no additional slot or chat announcement.
5. Confirm another Heroic without Renewal opens no Renewal dialog. Popcorn remains manual for Renewal.
